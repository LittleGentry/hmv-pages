HotfixMiniVerify 是一个演示 iOS 原生代码热更新机制的技术验证应用。

使用方法

  • 点“跑 Base”：以原生代码执行当前演示流程
  • 点“跑热更”：加载随包内置的补丁，以解释执行方式运行更新后的逻辑

两种模式都会在屏幕上输出执行日志，便于对照结果。

常见问题

应用需要联网吗？
不需要。应用完全离线运行，不发起任何网络请求。

为什么两种模式的输出不一样？
因为补丁更新了部分逻辑，这正是本应用要演示的效果。

应用会收集我的信息吗？
不会。详见隐私政策。

Last updated: October 14, 2026

HotfixMiniVerify is a technical demonstration app for native code hot-update mechanisms on iOS.

How to use

  • Tap "Run Base" to execute the current demo flow as native code
  • Tap "Run Hotfix" to load the bundled patch and run the updated logic through the interpreter

Both modes stream an execution log on screen so the two can be compared.

FAQ

Does the app need a network connection?
No. It runs fully offline and makes no network requests.

Why do the two modes differ?
Because the patch updates part of the logic — that is exactly what the app demonstrates.

Does the app collect my information?
No. See the Privacy Policy.
